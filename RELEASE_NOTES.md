
# Release notes — v1.0.0

## Included

- WGS, WGBS, annotation, statistics, and plotting scripts.
- Minimal cohort and background-design metadata.
- Conda/pip environment declarations.
- Workflow, portability, citation, release, and integrity documentation.

## Excluded by design

- Manuscript files.
- Rendered main and supplementary figures.
- Analysis result tables.
- Raw or intermediate sequencing data.
